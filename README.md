# 智能体集市

数字员工服务集市的独立 HTML 设计原型。包含员工目录、搜索筛选、能力预览、免费试用对话和订单预览。

## 运行

直接用浏览器打开 `index.html`，或运行：

```sh
python3 -m http.server 4187
```

## 交互范围

当前为可交互 HTML 界面。包含可浏览的示例对话和用量；新输入的对话与草稿保存在当前浏览器，附件只保存文件元数据，不上传或读取；未接入真实账号、AI、支付或订单。商品价格仅作原型参考。

## 技术

HTML、CSS、JavaScript；GSAP 3.13.0 与 ScrollTrigger。玻璃材质、动态减少偏好和不支持相关效果的浏览器均有降级。

## 我的工作台

- `workspace.html`：概览、历史对话、用量与额度。
- 对话与草稿保存在当前浏览器，可从工作台或最近对话继续。附件仅保存文件元数据。
- 包含6条示例会话和8次示例调用，用于展示Token、额度及状态；示例数字不代表真实账单。
- 本机工作记录独立保留，示例查看不会覆盖原记录；真实账号、数字员工和计费服务尚未连接。
