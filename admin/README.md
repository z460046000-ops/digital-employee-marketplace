# 智能体集市运营管理

本目录为可交互HTML原型。与同级 `embedded/` 共用运营配置，旧独立版首页不变。

## 入口

- 后台：`/admin/`
- 前台：`/embedded/`
- 同一个HTTP服务下打开两个入口，可即时查看管理配置对前台的影响。

## 功能

- **数字员工**：新增、编辑、上下架、置顶；拖动行首手柄或使用上下移动按钮调整顺序，点击“保存排序”生效。置顶组优先；有搜索或筛选时先清除条件再排序。使用次数和Token为最近30天示例统计。
- **积分与用量**：左侧模块菜单、中间企业列表、右侧企业积分；6家企业可切换，积分流水和Token调用明细支持时间、员工、类型及关键词筛选，并按当前筛选导出CSV。
- **运营**：Banner增改、启停、删除确认、运营位、跳转员工和排序。列表缩略图160×40，居中编辑弹窗含实时预览。目标员工下架时前台隐藏对应Banner。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| index.html | 页面结构、菜单、企业栏、表格和编辑弹窗 |
| admin.css | 统一样式、DIN、毛玻璃、入场与拖动动画、窄屏布局 |
| admin.js | 员工和Banner交互、排序保存、确认和错误反馈 |
| admin-billing.js | 企业切换、账单筛选、余额计算和CSV导出 |
| ops-store.js | 独立运营配置存储及跨页订阅 |
| billing-data.js | 6家企业的积分和Token示例数据 |

## 数据边界

运营配置保存在当前浏览器的 `agentwan.marketplace.operations.v1`，与已有对话、草稿和额度记录隔离；刷新可保留，同浏览器同来源页面可同步。默认示例只读加载，不自动写入。写入失败会保留输入并提示错误。

员工下架后停止创建新工作，旧对话仍可查看。新增员工用于展示和对话流程，不会自动连接真实AI服务。企业积分、Token及使用次数均为示例，未接真实账号权限、生产计量、支付或多人共享配置。

## 验证

已检查脚本语法、HTML引用、配置增改与稳定ID、上下架/置顶/排序、Banner异常目标、写入失败保护、企业切换/筛选/CSV；原有50点与每次10点的模拟对话、草稿和历史回归通过。桌面浏览器检查了页面、Banner弹窗、企业切换、排序保存及前台即时同步；前台窄屏单列卡片通过目视检查。原生拖动事件流程已通过运行测试，实际鼠标拖动手感及真实后端联调仍待人工确认。

动效尊重减少动态效果、减少透明度和高对比度设置。
