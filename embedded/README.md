原独立版继续使用仓库根地址。本目录为独立交互原型：标题式 Tab 切换智能体集市和场景集市，未选中项字体较小；工作台从右上角进入，作为独立页隐藏集市 Tab，“返回集市”位于标题上方左侧。卡片样式、场景和 D-DIN 字体沿用原版，取消员工单独标价和购买，主按钮为“开始使用”，点击后在右侧抽屉使用。

抽屉展示所有员工共用的免费示例额度：总计 1,000 点、剩余 860 点。点数仅为演示值，与 Token、金额的换算尚未确定，本机消息不扣额度。加 `?quota=empty&employee=content` 可预览额度不足：剩余 0 点、禁止发送且保留草稿，可打开抽屉内充值说明；套餐及支付未开放，未设置价格，不模拟充值成功。

本机草稿与消息使用独立存储命名空间。真实 AI、账号、计量和扣费尚未连接；附件未上传；示例回复和用量已标注。官网品牌资源原始地址与摘要见 assets/wdsheng/SOURCES.md。

本轮通过脚本语法、HTML 关联及资源检查；隔离脚本验证通过卡片入口、额度正常/不足状态、草稿保留、充值说明和工作台返回。浏览器布局与原生弹窗交互尚未复测。
