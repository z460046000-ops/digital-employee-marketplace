## 本版交互

- “智能体集市 / 场景集市”作为标题式 Tab 切换，选中项 28px、未选中项 22px；手机尺寸分别为 22px、18px。工作台从右上角进入，保持独立页面并隐藏集市 Tab；“返回集市”位于工作台标题上方左侧。支持键盘左右方向键切换，刷新保留当前分区；移除“企业服务平台”“AgentWan 提供能力”。
- 员工卡片样式、图片、分类和 D-DIN 数字字体复用独立版；五个场景的数据和封面也沿用原版。卡片取消员工单独标价和购买入口，主按钮统一“开始使用”。
- 点卡片、标题或“开始使用”直接打开该员工的右侧聊天抽屉。场景和历史对话同样在抽屉内打开。
- 抽屉初始为 50 个演示点，每次成功保存一条本机消息模拟扣 10 点，第 5 次后归零，第 6 次禁止发送；空提交或保存失败不扣点。不同员工共用当前页面的余量，刷新或“重置演示”恢复 50 点，不删除会话或草稿。点数与 Token、金额没有正式换算。
- “模拟无 Token”可立即归零；`?quota=empty&employee=content` 也可直达该状态。额度用完后会话区用紧凑提示行显示“前往workspace体验完整功能”，链接到原根地址并在新页打开，两版记录分别保存。充值说明中的链接也使用相同名称；套餐及支付尚未开放，未设置套餐价格，不模拟充值成功。
- 最近对话每行单独展示角色矢量图标、员工名称、对话摘要；草稿优先，其次最近用户消息，最后回退为会话标题。状态与时间弱化，整行仍可续接原员工和会话。
- 抽屉内显示员工能力、引导问题、输入和附件信息。关闭重开恢复该员工会话；草稿和消息保存到本机独立命名空间 `agentwan.marketplace.embedded.v1`，不读取或覆盖旧版记录。没有内容时只打开抽屉，不创建空会话。
- 当前消息不发送到真实服务，不产生 AI 回复、Token 消耗或真实扣费。示例回复与示例用量均标注；附件只保留名称等信息，未上传文件内容，刷新后需重新选择。
- 默认展示合作方外层布局；`?embed=1` 隐藏模拟顶部与左导航，便于后续放入合作方内容区。具体生产嵌入方式仍需与合作方确认。

## 文件与改动原因

| 文件 | 用途 |
| --- | --- |
| index.html | 宿主布局、标题式 Tab、目录、工作台、聊天抽屉和额度/充值说明 |
| embedded.css / embedded-layout.css | 宿主与抽屉样式、字号层级、额度展示和嵌入尺寸适配 |
| legacy-market.css / legacy-scenes.css | 将旧版目录、卡片和场景样式限定到主内容区，避免影响宿主外壳 |
| embedded.js | 搜索分类、Tab、抽屉与会话恢复、示例额度及不足状态；没有请求真实业务接口 |
| embedded-store.js | 复用原本机记录逻辑，改用独立存储 key |
| catalog.js / scene-catalog.js / workspace-examples.js | 复用员工、场景及明确标注的示例数据 |
| assets/ | 原版封面和 D-DIN 字体；wdsheng/ 中为官网真实 Logo、favicon 和导航图标 |

品牌资源来自官网公开静态文件，原始地址和摘要见 [SOURCES.md](assets/wdsheng/SOURCES.md)。头部使用实际产品 Logo `platform-logo.svg`，首页、对话、需求大厅、服务大厅使用原站导航图标。官网没有本模块的专用导航图标，智能体集市图标沿用临时小图标。
